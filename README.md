# skillmatch
 “SkillMatch JS: Simulador de Compatibilidade com Vaga Front-End Júnior”  

Desenvolvido como parte de atividade avaliatória de curso de JavaScript seguindo requisitos pré definidos (tarefas, funcionais, estruturais e para apresentação).
A atividade proposta é a criação de um programa para o RH da empresa, reduzindo tempo de análise entre perfil técnico de candidatos com os requisitos das vagas disponíveis para Front-end. A aplicção criada deverá retornar ao RH a compatibilidade prevista entre candidato e as vagas disponíveis, para isso analisar as habilidades (do candidato, exigidas pela vaga e as que estão faltando para indicar ao candidato o que precisa ser desenvolvido).

Para para resolver o desafio proposto criei o seguinte organograma de resolução: 
 1. Analisei o desafio: identificando os dados que entram (curriculum candidatos, vagas disponíveis, habilidades); o resultado esperado; e as regras e limites específicos do projeto. Utilizei a ferramenta Kanban para organização criando 5 categorias (backlog, to do, doing, revisão e concluído) utilizando o Trello (acesse pelo link: https://trello.com/invite/b/6ad6b5f23ae8a46d42687f7a/ATTI1c436f91bd573efaf22f9da4d841613b2CA906B2/projeto-sr) e anotações manuais adicionais.
 2. Desenhei a lógica necessária: primeiro com um pseudocódigo (no próprio caderno), dividindo o problema maior em menores e escrevendo o caminho da resolução.
 3. Executei o código no terminal do VS Code verificando a sintaxe correta JS. Iniciei pelo npm install prompt-sync e acessei o arquivo pelo node skillmatch.js 
 4. Testar e otimizar (refatorar: verificar se o código pode ficar mais claro).
